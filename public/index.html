      AI engine

      Prefer Ollama on your own machine (free, private). Gemini is optional for machines that cannot run a local model. The offline rules engine always works as a fallback.

      Running n8n in Docker with Ollama on the host? Use http://host.docker.internal:11434.

      Secrets & channels

      Values are read from .env on the server. They are never shown here.

        Telegram

        Create a bot with @BotFather, put the token in .env, then set TELEGRAM_MODE=polling. Only IDs in ALLOWED_TELEGRAM_USER_IDS can trigger workflows.

          Google Sheets

          Create a spreadsheet named AI Digital Office with tabs Tasks, Drafts, Leads and Daily Log. Export the current data and import it, or connect the n8n Google Sheets node.

          Taskscsv Draftscsv Leadscsv Daily Logcsv

          Column order matches Chapter 14 of the guide exactly.

          Deployment checklist

          From the guide's final page. Tick these before you call the office “live”.

          • Engine reachable (Ollama running or Gemini key set)
          • Telegram bot token stored only in credentials
          • Only your Telegram user ID can trigger workflows
          • AI output validated before writing to Sheets
          • Every draft requires Approve, Revise, or Reject
          • No workflow publishes, messages, spends, or deletes without approval
          • Workflow export saved to GitHub
          • Data volume and Sheets backed up
          • Error alerts and cost limits configured

          Data

          Everything lives in data/db.json on your machine. Back it up before resetting — the reset cannot be undone.

          Reset keeps the app running and optionally restores the Chapter 4 demo rows.
